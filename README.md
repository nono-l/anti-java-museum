# Java 宇宙敵博物館（アンチJava）

Java を「宇宙の敵」として告発するインタラクティブ博物館 + カイロソフト風精神崩壊シミュレータ。

## 含まれるもの

- 展示パネル（NPE / 検査例外 / 売り逃げ / ログ握りつぶし / SEV≥70 罪状など）
- タブ: 展示 · 崩壊シミュ · 掲示板
- **ジャバだけ社畜物語**（1日1ターン管理シム）
- エンディング結果の `/Game/{code}` シェアリンクと OG カード

## 開発

```bash
npm install
npm run dev      # 0.0.0.0:8080
npm run build
npm run typecheck
```

## 技術

React 19 · TanStack Start · Vite · Tailwind v4 · TypeScript

風刺・デモ用コンテンツです。
